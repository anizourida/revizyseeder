POST Add Energy Auth Required

/api/v1/student/add-energy
Request Body
Parameter Type Description

    "data": {
        "next_available_at": "2026-01-09T23:59:59+00:00",

GET Weekly Mastery Auth Required

/api/v1/units/{uniteId}/weekly-mastery

Get the student's weekly mastery for all weeks (1-5) within a specific unit. Uses coverage-weighted mastery where unattempted concepts count as 0.

URL Parameter

uniteId: The ID of the unit.

Response
{
    "message": "Weekly mastery retrieved successfully",
    "data": {
        "unit_id": 1,
        "weeks": [
            { "week": 1, "mastery": 0.82, "status": "strong", "coverage": 0.9, "is_free": true },
            { "week": 2, "mastery": null, "status": "premium_locked", "coverage": 0, "is_free": false },
            { "week": 3, "mastery": null, "status": "premium_locked", "coverage": 0, "is_free": false },
            { "week": 4, "mastery": null, "status": "premium_locked", "coverage": 0, "is_free": false },
            { "week": 5, "mastery": null, "status": "premium_locked", "coverage": 0, "is_free": false }
        ]
    }
}
Status Thresholds
Status Condition
premium_locked Week is not free AND user is not subscribed (requires subscription)
locked No concepts attempted (but week is accessible)
weak mastery < 0.4
medium 0.4 ≤ mastery < 0.75
strong mastery ≥ 0.75

coverage = attempted concepts / total concepts in week

is_free = whether this week is free for all users (admin-configurable per unit)

            "children": [
                {
                    "id": 3,
                    "parent_id": 1,
                    "order_index": 0,
                    "name": "Land Transport",
                    "description": "Cars, buses, trains",
                    "subject": "francais",
                    "is_free": false,
                    "cover_image": { ... },
                    "flashcards_count": 10,
                    "children_count": 0,
                    "grade_id": 1,
                    "created_at": "..."
                },
                {
                    "id": 4,
                    "parent_id": 1,
                    "name": "Air Transport",
                    ...
                }
            ]
        }
    ]
}
Field Definitions
Field Type Description
parent_id int|null ID of parent category. null for top-level categories.
children_count int Number of direct subcategories.
children array Nested array of subcategories (only present for top-level categories).
flashcards_count int Number of flashcards directly in this category.
is_free boolean Whether this category is accessible without subscription.
Hierarchy Notes
  • Only top-level categories (parent_id = null) are returned at the root level.
  • Subcategories are nested inside their parent's children array.
  • Maximum nesting depth is 2 levels (category → subcategory).
  • A category can have either subcategories OR flashcards, not both.

GET Get Available Ad Auth Required

/api/v1/ads/available

Get an eligible video ad for the current user based on targeting rules and frequency caps.

Query Parameters
Parameter Type Description
os string Optional. Device OS: ios or android. Used for OS targeting.
Targeting Logic

An ad is eligible if ALL of the following are true:

  • Ad is is_active = true
  • Current time is within start_at and end_at (if set)
  • Student's gender matches target_gender (or ad targets "both")
  • OS matches target_os (if OS provided, otherwise ignored)
  • If student is subscribed, allow_for_subscribers must be true
  • Student's grade is in ad's grade list (or ad has no grade restrictions)
  • Ad hasn't exceeded max_impressions or max_clicks
  • Ad hasn't exceeded max_daily_impressions for today
  • Student hasn't exceeded max_per_user_daily_impressions for this ad today
Response (200 OK)
{
    "ad": {
        "id": 1,
        "video": {
            "id": "abc123...",
            "url": "https://...r2.dev/files/video.mp4"
        },
        "cover": {
            "id": "def456...",
            "url": "https://...r2.dev/files/cover.jpg"
        },
        "external_link": "https://example.com/promo",
        "cta_text": "Learn More",
        "skip_after_seconds": 5,
        "show_cta_after_seconds": 3
    }
}
Response (204 No Content)

No eligible ads available for this user at this time.

GET Monthly Report Auth Required

/api/v1/reports

Get daily snapshots of student performance for a specific month. Past days are frozen (immutable), today is recomputed live.

Query Parameters
Parameter Type Description
month int Target month (default: current).
year int Target year (default: current).
Response
{
    "2025-12-01": {
        "period": {
            "start": "2025-12-01 00:00:00",
            "end": "2025-12-01 23:59:59"
        },
        "questions": {
            "total": 15,
            "correct": 12,
            "incorrect": 3
        },
        "concepts": {
            "count": 3,
            "average_mastery": 75.5,
            "details": [
                {
                    "concept_id": 1,
                    "concept_name": "Addition",
                    "mastery_percentage": 85.2
                },
                {
                    "concept_id": 2,
                    "concept_name": "Subtraction",
                    "mastery_state": "learning"
                }
            ]
        },
        "quizzes": {
            "count": 2,
            "total_time_seconds": 320
        }
    },
    "2025-12-02": { ... }
}
Mastery Display Logic

For concepts with weighted_attempts < 3, a mastery_state is returned instead of mastery_percentage:

  • "getting_started" - 1 attempt
  • "learning" - 2 attempts

For 3+ attempts, mastery_percentage is returned as a number.
